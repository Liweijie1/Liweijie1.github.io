1.鼠标悬浮特效
	当鼠标悬浮在绑定了点击事件和超链接上时，鼠标的箭头就会变成一把剑
	该特效代码位于js文件夹下的index.js和header.js中
2.视频特效
	点击播放视频按钮时，页面中心弹出视频，点击视频以外的地方可关闭视频
	该特效代码位于js文件夹下的index.js和xw.js中
3.点击头像切换内容特效
	点击index.html里右侧的人物头像时，人物图片、介绍内容等会切换到头像对应人物的内容。
	该特效代码位于js文件夹下的index.js中
4. 轮播图特效
	轮播图会自动轮播图片，点击轮播图左右两侧的箭头可改变显示的图片。
	该特效代码位于js文件夹下的index.js中
5.滑动选项卡特效
	当鼠标悬浮或点击在gw.html和xw.html顶部导航栏的文字时，选项卡会滑动到鼠标悬浮或点击的文字上方
	该特效代码位于js文件夹下的header.js中
6.高光特效
	当鼠标悬浮或点击在gw.html和xw.html顶部导航栏的文字时，选项卡会滑动到鼠标悬浮或点击的文字上方
	该特效代码位于js文件夹下的header.js中
7.上拉下拉特效
	当鼠标点击gw.html和xw.html顶部导航栏的“角色”和“新闻”时，二级菜单就会以上拉下拉的方法显示隐藏
	该特效代码位于js文件夹下的header.js中
8.淡入淡出特效
	当鼠标点击gw.html和xw.html顶部导航栏的“漫画”和“社区”时，二级菜单就会以淡入淡出的方法显示隐藏
	该特效代码位于js文件夹下的header.js中
9.显示隐藏特效
	当鼠标点击gw.html和xw.html顶部导航栏的“赛事”时，二级菜单就会显示或隐藏
	该特效代码位于js文件夹下的header.js中
